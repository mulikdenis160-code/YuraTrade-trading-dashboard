---
name: Signal statistics integrity
description: Rules for trustworthy outcome totals and performance claims in PRIME BOT.
---

PRIME BOT actual performance totals and hit rates must come from verified terminal signal-series outcomes. Keep draws out of the hit-rate denominator, count an overlay sequence as one series, and identify that verified data is local to this browser rather than platform-wide. A fixed demo panel is allowed only when prominently labeled as non-real, kept separate from actual statistics, and never saved or increased over time.

**Why:** The user approved a fixed, explicitly labeled demo example but did not want it written into actual statistics; presenting synthetic performance as historical results would mislead users.

**How to apply:** When changing the journal, statistics, or performance copy, preserve the verified-outcome rules and clearly state data scope. Keep demo UI static and distinct, and treat historical results as non-predictive.
